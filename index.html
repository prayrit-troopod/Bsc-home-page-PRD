What does each one do?

The Figma shows what the page looks like. This defines what it does — every clickable part and where it goes, what content fills it, how it moves, what it shows when there’s nothing to show. Each panel opens with what’s already in the design, so you only write what the design can’t say. Six questions and one table per section.
